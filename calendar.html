Import and connection details

In Google Calendar on a computer, open Settings → Import & export → Export. Unzip the download, then import the .ics files here. All-day events block their local calendar day; events marked “Free” do not block time. Files are read on this device.

Google sign-in reads calendar names and busy time. A Google OAuth web client ID must be added to calendar.googleClientId in config.js before it works. Setup instructions ↗. Sign into your own account, then choose which calendars to include from the checklist. If your partner shares their Google calendar's free/busy information with you, enter their explicit calendar ID in the other panel and press “Load shared calendar” to read it with your existing connection. Leave “primary” only for your own main calendar. Connected calendars update each minute while this tab is visible, and when you return to it. Expired sign-in asks you to reconnect; it never opens a popup automatically.

Share codes contain a name, time zone, chosen week, and busy intervals. They contain no event titles or Google tokens. Send the code privately to your partner, who can paste it into their other panel. A code is a snapshot, not live synchronization; generate a new one after changes.

Names, time zones, available-hour preferences, and chosen calendar IDs are saved only in this browser. Calendar files, busy data, calendar names, and Google tokens stay in memory and disappear on refresh. Free windows are suggestions based on the calendars you supplied. “Add to calendars” downloads a plan for the minimum selected duration; import it into your calendars to reserve it.

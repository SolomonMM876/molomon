How requests are handled

Codex checks submitted requests about every 15 minutes when your computer and the Codex app are running, and this page is signed in. The website itself does not run an agent. Private storage and the scheduled check must be configured first.

Pending → Preparing → Ready. Done means the change is finished; Needs input means a detail or decision is missing. Response summaries appear on each request. Prepared website changes wait for your approval before publication.

A request describes a change to Molomon. It is never treated as a shell command or authority to access unrelated files or accounts. Invitations and private credentials stay out of the public website.

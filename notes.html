Saving and sharing

Use books to group lists, plans, and ideas. Each line in a note is one bullet point.

Sign in with one of your two configured Google accounts, then open the same private invitation to edit shared notes. An invitation alone grants no access. Keep invitations out of the public hub.

Shared edits save when connected. If the same note changes while you are editing, your draft stays open; load the latest version or save your draft as a separate note. Offline, a signed-in account can read the last cached notes and keep a draft on this device.

Device notes are separate from shared notes. Export a backup, open your shared space, then import it to move a copy there. Imports add notes and never replace existing ones. Backups contain note text and author names; store them privately.
